# STM32F107VCT6-JWRobot —— 智能巡检机器人系统

### 🎯 项目定位
本项目是基于 **STM32F107VCT6** 微控制器的**轻量化智能巡检机器人系统**，面向**工业场景（如电力机房、仓储物流、实验室）**与**科研实验**需求，实现**环境感知、自主避障、人机交互、数据追溯**的全链路闭环巡检。系统以“**低功耗、高可靠、易扩展**”为核心设计理念，构建从硬件驱动、算法决策到数据管理的完整技术栈。

### 🛠️ 核心技术架构

#### 1. 硬件层：高集成度嵌入式平台
- **主控芯片**：STM32F107VCT6（ARM Cortex-M3 内核，72MHz 主频，256KB Flash + 64KB RAM），支持丰富外设（CAN、USART、SPI、I2C、TIM 等），满足多传感器并发采集与实时控制需求。
- **感知模块**：
  - 温湿度传感：DHT11/DHT22（精度 ±0.5℃ / ±2%RH），实时采集环境温湿度；
  - 超声波测距：HC-SR04（测距范围 2cm~400cm，精度 ±3mm），实现障碍物距离检测；
  - 避障辅助：红外/光电传感器（可选），增强复杂环境下的感知冗余。
- **执行模块**：
  - 电机驱动：L298N/TB6612（双路 PWM 调速，支持正反转），实现机器人移动控制；
  - 状态指示：RGB LED/蜂鸣器，通过闪烁频率、颜色、声音反馈系统状态（避障、故障、数据上报等）。
- **通信模块**：USART/UART（对接上位机/串口屏）、CAN（工业级通信，可选）、蓝牙（手机端交互，可选），支持数据实时上报与指令下发。

#### 2. 软件层：模块化嵌入式开发体系
- **驱动层**：封装各传感器（DHT、HC-SR04）、执行器（电机、LED）的底层驱动，采用**分层解耦**设计，便于硬件替换与扩展。
- **中间件层**：
  - 任务调度：基于 **FreeRTOS**（可选）或裸机状态机，实现多任务（避障、数据采集、通信、UI）的优先级调度；
  - 数据处理：传感器滤波（滑动平均、卡尔曼滤波）、温湿度补偿算法、测距数据校准。
- **应用层**：
  - 自主避障算法：基于**超声波距离阈值**与**红外反射**的复合判断逻辑，实现“遇障即停 + 动态绕行”（可扩展 A* 路径规划）；
  - 巡检逻辑引擎：支持**定点巡检**（预设点位）、**随机巡检**（动态生成路径）、**触发式巡检**（异常数据驱动）；
  - 人机交互协议：自定义串口指令集（如 `CMD_SET_FREQ 2` 调节警示灯频率，`CMD_SWITCH_POINT 3` 切换巡检点），兼容上位机 GUI 与手机 APP；
  - 数据管理：基于 **环形缓冲区** 实现历史数据缓存，支持 **SD 卡存储**（FatFS 文件系统）或 **无线透传**（蓝牙/WiFi），数据格式采用 JSON/CSV，便于后期分析。

### ⚙️ 核心功能详解

#### 1. 智能避障与状态指示
- **多级避障策略**：
  - 一级预警：超声波距离 < 50cm 时，LED 慢闪 + 减速；
  - 二级制动：距离 < 20cm 时，电机急停 + LED 快闪 + 蜂鸣器报警；
  - 三级恢复：障碍移除后，自动恢复巡检（支持手动/自动模式切换）。
- **状态可视化**：通过 RGB LED 颜色编码（红=故障，黄=预警，绿=正常），结合蜂鸣器音调区分异常类型，提升现场运维效率。

#### 2. 可调控闪灯频率
- **动态调节机制**：支持通过串口指令（如 `CMD_SET_FREQ 1/2/3`）或手机 APP 滑块，实时调整警示灯闪烁频率（1Hz/2Hz/5Hz），适配不同场景的警示强度需求。
- **频率记忆功能**：掉电后自动保存最后一次设置，上电即恢复，避免重复配置。

#### 3. 人机交互巡检
- **多模式切换**：
  - **手动模式**：通过上位机/串口屏发送坐标指令（如 `CMD_GO_TO X10 Y20`），机器人精准移动至指定点位；
  - **自动模式**：按预设巡检路线（如“点 A → 点 B → 点 C”）循环执行，支持定时/循环两种触发方式；
  - **应急模式**：长按按键 3s，立即中断当前任务，返回原点或进入安全区域。
- **交互界面**：支持 LCD1602/OLED 显示当前点位、温度、距离、电池电量等关键参数，提升操作直观性。

#### 4. 多维环境感知
- **温湿度监测**：DHT22 传感器每秒采样一次，数据经滑动平均滤波后输出，确保精度；
- **超声波测距**：HC-SR04 采用“触发-回波”脉冲法，测距值经卡尔曼滤波平滑处理，抗干扰能力强；
- **数据融合**：温湿度 + 距离 + 时间戳，构建**环境状态向量**，为后续分析提供结构化数据。

#### 5. 数据记录与上报
- **本地存储**：采用 FatFS 文件系统，将数据写入 SD 卡（格式：CSV），每条记录包含：`时间戳, 点位ID, 温度, 湿度, 距离, 状态`，支持历史数据回溯；
- **远程上报**：通过 USART/CAN/蓝牙，将实时数据打包为 JSON 格式（如 `{"time": "2026-05-29 10:00:00", "point": "A", "temp": 25.3, "humi": 60.1, "dist": 120.5, "status": "normal"}`），推送至上位机或云端平台；
- **数据压缩**：采用差分编码 + 时间戳对齐，减少传输数据量，提升通信效率。

### 🧩 扩展能力
- **硬件扩展**：预留 I2C/SPI 接口，可外接摄像头（视觉识别）、气体传感器（VOC、CO2）、GPS 模块（户外定位）；
- **软件扩展**：支持接入 MQTT 协议，对接物联网平台（如阿里云、ThingsBoard），实现远程监控与告警；
- **算法扩展**：可集成 PID 电机控制、SLAM 建图、AI 异常检测（如基于 TensorFlow Lite for Microcontrollers）。
