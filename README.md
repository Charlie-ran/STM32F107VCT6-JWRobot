# STM32F107VCT6-JWRobot
# 🤖 智能巡检机器人

一个基于 [STM32F107VCT6] 的智能巡检机器人项目。该机器人具备自主避障、环境温湿度测量、超声波测距以及人机交互巡检功能，并能自动记录与上报历史数据。

## ✨ 核心功能

- **智能避障与状态指示**：遇到障碍物自动停止，并通过闪烁 LED 灯进行状态报警。
- **可调控闪灯频率**：支持通过指令或交互动态控制警示灯的闪烁频率。
- **人机交互巡检**：支持手动切换不同的巡检点位，灵活适应巡检需求。
- **多维环境感知**：集成温度传感器与超声波模块，实时测量环境温度与距离。
- **数据记录与上报**：自动记录每个巡检点的历史测量值，并定时/实时发送给用户。
